# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.0.7

### Changed

- Improved README formatting and the compatibility matrix.

### Fixed

- Corrected the MIT license text.

## 0.0.6

### Added

- `FileDigest` constructors for `File`, `XFile`, bytes, and byte streams.
- `DigestType` and `convert` for selecting digest algorithms dynamically.
- A benchmark for file-digest performance.

### Changed

- Modernized the cross-platform digest API and implementation.
- Limited the web worker asset to web builds.
- Raised the minimum SDK requirements to Dart 3.10 and Flutter 3.38.
- Improved API documentation and README guidance.
